News Summarizer

NLP Vibe Coding Challenge · Solo Project · Python · Streamlit

🔗 View on GitHub

What It Does

A small solo-built tool for a rapid "vibe coding" NLP challenge: pull live news from an RSS feed, let the user pick which articles to summarize, generate summaries with an LLM, categorize each article by topic, and visualize the topic breakdown.

  • Fetches news articles live from RSS feeds (e.g. BBC World)
  • Lets the user select articles and generate LLM summaries — with a safe fallback if no API key is configured, so the app still works without one
  • Categorizes articles by topic (Business, Tech, Politics, Sports, Health, Entertainment, World)
  • Visualizes topic distribution with a bar chart

Why the Fallback Design

Since this was a timed coding challenge meant to be run and judged quickly, I designed the summarization step to degrade gracefully: if an OpenAI API key isn't set, the app falls back to a safe, non-LLM summarization method instead of failing outright. That's a small design choice, but it's the difference between a demo that always works and one that breaks the moment an API key is missing or rate-limited.

Tech Stack

  • Python, Streamlit
  • Feedparser (RSS fetching)
  • Pandas, Matplotlib
  • OpenAI API (optional, with fallback)

Why This Project Matters

This one is small on purpose — it was a timed challenge, not a term-long project — but it's fully my own, end to end. It shows I can take a vague prompt ("build an NLP news tool") and ship something working, with sane defaults and failure handling, in a short window.
