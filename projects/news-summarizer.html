News Summarizer

Python Streamlit LLM Feedparser Matplotlib
View on GitHub

The Problem

A timed build challenge: turn a vague prompt — "build an NLP news tool" — into something working and demoable, fast, with sane defaults and failure handling.

Approach

A solo app that pulls live news, summarizes it, and visualizes what it's about:

  • Fetch — live articles from RSS feeds (e.g. BBC World) via Feedparser
  • Summarize — the user picks articles and an LLM summarizes them, with a non-LLM fallback when no API key is set so the demo never breaks
  • Categorize — each article tagged by topic (Business, Tech, Politics, Sports, Health, Entertainment, World)
  • Visualize — topic distribution as a bar chart

Results

  • Working end-to-end app shipped inside the challenge window
  • Graceful degradation — runs with or without an API key

Reflections

Small on purpose, but fully my own end to end. The fallback design is the difference between a demo that always works and one that breaks the moment an API key is missing or rate-limited.
